# Release v2.1.0 - 发布说明

## 版本信息
- **版本号**: 2.1.0
- **发布日期**: 2026-07-24
- **Python 版本**: 3.10+

## 新增功能

### 1. Transformer 模型
- 基于 PyTorch 的 Transformer 架构
- 支持红球顺序生成和蓝球二分类
- 当 PyTorch 不可用时自动降级

### 2. 多期联合预测
- 预测未来 N 期的号码出现概率
- 趋势分析：稳定号码、上升趋势号码
- 综合推荐功能

### 3. 特征工程自动化管道
- 可配置的特征提取器
- 特征重要性分析
- 特征选择（基于方差）
- 配置保存/加载

### 4. 回测胜率统计
- 各奖级中奖次数统计
- 总投入/总回报/收益率计算
- 号码频率分析
- 热号/冷号检测

### 5. 自定义过滤规则 UI
- 双色球：比较期数、红球重合上限、蓝球禁止相同
- 福彩3D：启用开关、比较期数、相同号码上限、和值范围
- 七乐彩：启用开关、比较期数、基本号重合上限、和值范围

### 6. Excel 导出
- 支持导出 Excel (.xlsx) 格式
- 带样式表头和冻结首行
- 自动列宽调整

### 7. 异步网络请求
- 基于 asyncio 的异步工作器
- ThreadPoolExecutor 并发执行
- 非阻塞 UI 线程

### 8. 性能优化
- NumPy 向量化特征提取
- 特征缓存（LRU）
- 批量处理
- 内存优化

## 改进

### 增量模型训练
- 支持模型增量更新
- 自动判断增量/全量训练
- 减少训练时间

### CI/CD
- GitHub Actions 自动化测试
- 多平台支持（Ubuntu/Windows）
- 多 Python 版本支持（3.10/3.11/3.12）

### 代码质量
- 统一使用 Python 3.10+ 类型注解
- 异常处理分层优化
- 日志格式统一化

## 升级指南

### 从 v2.0.0 升级

1. 备份现有数据
2. 更新代码
3. 安装新依赖：`pip install -r requirements.txt`
4. 运行测试：`python -m pytest tests/`
5. 启动应用：`python main.py`
