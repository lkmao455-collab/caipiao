## 1. 什么是机器学习？

机器学习（Machine Learning）就是让计算机**从数据中学习规律**，然后用学到的规律对新数据做判断。

传统编程：

```
你写规则 → 计算机执行 → 得到结果
```

机器学习：

```
你给数据 + 正确答案 → 计算机自动学习规则 → 用规则预测新数据
```

例子：

- 传统方法：你告诉计算机“如果红球 06 连续 10 期没出，下期就买 06”。
- 机器学习：你给计算机 3000 期历史开奖数据，它自己总结规律。

---

## 2. 什么是 XGBoost？

XGBoost = **eXtreme Gradient Boosting**（极限梯度提升）。

它是一种集成学习方法，核心思想是：

> 用很多个简单的决策树（Decision Tree）组合成一个强大的模型。

### 2.1 决策树是什么？

决策树就像你玩“猜数字”时问的一系列问题：

```
这个号码最近 10 期出现次数 > 2 次吗？
├── 是 → 它下期出现的概率高
└── 否 → 继续问：它遗漏值 > 15 吗？
    ├── 是 → 概率中等
    └── 否 → 概率低
```

一棵树通常不够准，所以 XGBoost 会训练很多棵树，**把它们的结果加起来**。

### 2.2 Boosting 是什么？

Boosting 的意思是“逐步提升”：

1. 先训练第一棵树，发现有些样本预测错了。
2. 再训练第二棵树，专门去修正第一棵树的错误。
3. 再训练第三棵树，修正前两棵树的错误。
4. 反复迭代，最后把所有树的结果加权求和。

XGBoost 是 Boosting 的一种高效实现，训练速度快、效果好，是数据科学竞赛中的常用算法。

## 3. 本项目的问题定义

我们要解决的问题可以描述为：

> 给定最近 `lookback` 期的开奖数据，预测下一期每个红球和蓝球是否会出现。

因为每个号码只有“出现”或“不出现”两种结果，所以这是一个**二分类问题**。

本项目不是直接预测“一注完整号码”，而是分别预测：

- 红球 01 会出现吗？
- 红球 02 会出现吗？
- ……
- 蓝球 01 会出现吗？
- ……

一共训练 **33 个红球分类器 + 1 个蓝球多输出分类器**。

---

## 4. 数据准备：特征与标签

机器学习需要两样东西：**特征（X）** 和 **标签（y）**。

### 4.1 标签（y）是什么？

标签就是我们要预测的“正确答案”。

对于某期开奖，如果红球 06 出现了，标签就是 `1`；没出现就是 `0`。

例如：

| 期号 | 开奖号码 | 红球06标签 | 红球07标签 |
|------|----------|------------|------------|
| 2026073 | 06 12 18 23 28 31 + 09 | 1 | 0 |
| 2026074 | 07 15 19 24 29 33 + 03 | 0 | 1 |

### 4.2 特征（X）是什么？

特征是帮助模型做判断的“线索”。

本项目用到的特征包括：

| 特征类型 | 例子 |
|----------|------|
| 号码频率 | 红球 06 在最近 50 期出现了几次 |
| 遗漏值 | 红球 06 已经多少期没出现 |
| 奇偶比 | 最近几期开奖红球奇偶比例 |
| 大小比 | 最近几期开奖红球大小比例 |
| 和值 | 最近几期红球和值的均值/方差 |
| 时间特征 | 月份、日期、星期几 |

### 4.3 滑动窗口

我们不能用未来的数据预测过去，所以采用**滑动窗口**：

```
用第 1~50 期  预测 第 51 期
用第 2~51 期  预测 第 52 期
用第 3~52 期  预测 第 53 期
...
```

每一组窗口数据生成一个训练样本。

## 5. 训练流程详解

### 5.1 整体流程

```
1. 加载历史开奖数据
2. 构建特征矩阵 X 和标签 y
3. 为每个号码训练一个 XGBoost 二分类器
4. 保存训练好的模型
5. 用最新一期数据预测下一期概率
```

### 5.2 红球模型训练

代码逻辑（简化版）：

```python
for i in range(33):  # 33 个红球
    model = XGBClassifier(random_state=42)
    model.fit(X, y_red[:, i])
    red_models.append(model)
```

- `X`：形状 `(样本数, 特征数)`，所有红球共享同一套特征。
- `y_red[:, i]`：第 i 个红球在所有样本上的标签（0 或 1）。

### 5.3 蓝球模型训练

蓝球只有 1 个，但一期开出 1 个蓝球，相当于要从 16 个蓝球中选出 1 个。

这里用 `MultiOutputClassifier` 同时训练 16 个二分类器，每个分类器判断一个蓝球是否会出现。

### 5.4 类别不平衡处理

双色球里每个号码出现的次数很少（红球每期只出现 6/33，蓝球 1/16），所以标签中 `0` 远多于 `1`。

这叫**类别不平衡**。本项目用 `scale_pos_weight` 参数给正样本（出现）更高权重，让模型更重视少数类。

## 6. 模型参数白话解释

本项目的 XGBoost 参数如下：

```python
XGBClassifier(
    n_estimators=100,      # 训练 100 棵树
    max_depth=4,           # 每棵树最多 4 层
    learning_rate=0.1,     # 每棵树的贡献打 0.1 折
    subsample=0.8,         # 每次随机用 80% 的数据
    colsample_bytree=0.8,  # 每次随机用 80% 的特征
    objective="binary:logistic",  # 二分类，输出概率
    eval_metric="logloss", # 用 logloss 评估好坏
    random_state=42,       # 固定随机种子，结果可复现
)
```

### 6.1 n_estimators = 100

树的数量。树越多，模型越复杂，但也越容易过拟合。

### 6.2 max_depth = 4

每棵决策树的最大深度。深度越大，模型学习能力越强，但也越容易记住噪声。

### 6.3 learning_rate = 0.1

学习率，也叫“收缩率”。每棵新树对最终结果的贡献会被打折。学习率小，训练更稳定，但需要更多树。

### 6.4 subsample = 0.8

每次训练一棵树时，随机抽取 80% 的样本。这能防止模型死记硬背，提高泛化能力。

### 6.5 colsample_bytree = 0.8

每次训练一棵树时，随机抽取 80% 的特征。也是为了增加多样性，防止过拟合。

### 6.6 objective = "binary:logistic"

目标函数。`binary:logistic` 表示二分类问题，输出一个 0~1 之间的概率。

### 6.7 eval_metric = "logloss"

评估指标。logloss（对数损失）衡量预测概率与真实标签的差距，越小越好。

## 7. 预测与概率

训练完成后，模型可以对“最新一期”做预测：

```python
red_proba = model.predict_proba(latest_features)[:, 1]
```

这行代码得到的是：

> 在最新特征下，每个号码出现的概率。

概率值在 0~1 之间，越接近 1 表示模型越“看好”这个号码。

**注意**：这个概率只是模型基于历史数据学习到的统计倾向，**不代表真实中奖概率**。

---

## 8. 特征工程做了什么

特征工程是机器学习中非常重要的一步。同样的算法，特征越好，效果越好。

本项目的特征工程在 `caipiao/ml/features.py` 中：

1. **单个号码特征**
   - 最近 `lookback` 期出现次数
   - 距离最近一次出现有多少期
   - 出现频率

2. **窗口整体特征**
   - 红球和值的均值、标准差
   - 奇偶比均值
   - 大小比均值
   - 蓝球号码均值

3. **时间特征**
   - 最后一期的月份、日期、星期几

这些特征帮助模型捕捉短期统计规律，但无法捕捉“随机性”。

## 10. 常见误区

### ❌ 误区 1：XGBoost 能预测彩票

**真相**：彩票开奖是独立随机事件。XGBoost 只能拟合历史数据中的统计模式，这些模式在未来不一定重复。

### ❌ 误区 2：概率高就一定中奖

**真相**：模型输出的概率是“历史回顾概率”，不是“未来发生概率”。即使某号码概率最高，下期开出的真实概率仍然是 6/33（红球）或 1/16（蓝球）。

### ❌ 误区 3：增加模型复杂度就能提高中奖率

**真相**：复杂模型更容易过拟合，也就是把历史噪声当成规律。对随机数据，简单模型反而更稳健。
