## Bug Template

```markdown
### BUG-XXX: [标题]

- **Priority**: P0/P1/P2/P3
- **Status**: Open / In Progress / Fixed / Won't Fix
- **Module**: [受影响模块]
- **Description**: [问题描述]
- **Reproduce**: [复现步骤]
- **Expected**: [预期行为]
- **Actual**: [实际行为]
- **Root Cause**: [根因分析]
- **Fix**: [修复方案]
- **Date Found**: [发现日期]
- **Date Fixed**: [修复日期]
```

## Priority Definitions

- **P0**: 崩溃 / 数据丢失 — 立即修复
- **P1**: 核心功能不可用 — 24h 内修复
- **P2**: 功能异常但有 workaround — 本周修复
- **P3**: 体验问题 / 优化 — 排期修复
