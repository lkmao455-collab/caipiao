# 福彩3D「分散随机」生成策略 — 完成摘要

## 1. 需求背景

在福彩3D现有策略之外，新增一个**完全随机、不依赖历史数据**的生成策略。要求：

- 不使用任何历史开奖记录；
- 生成的多注号码在概率空间上尽量分散，避免聚集；
- 新策略独立实现，不引用/复用已有策略逻辑；
- 在 UI 的策略下拉列表中可直接选择。

## 2. 设计思路

### 2.1 概率空间

福彩3D单注号码为 `(百位, 十位, 个位)`，每位 0–9，共有 `10×10×10 = 1000` 个等概率样本点。

### 2.2 分散性度量

把每注号码看成三维空间中的点 `(b, s, g)`，使用**欧氏距离**衡量两注号码的相似度：

```
d(p, q) = sqrt((b1-b2)^2 + (s1-s2)^2 + (g1-g2)^2)
```

距离越大，两注号码在视觉和数值上越不相似。

### 2.3 生成算法

1. **全局随机候选池**：从 1000 个号码中无放回随机抽取 `pool_size`（默认 `n × 5`）个候选；
2. **最小间距贪心选择**：从候选池中先选一个随机起点，之后每次选择距离已选集合最远的候选加入结果；
3. **局部交换优化**：对结果进行若干轮随机交换尝试，若交换后整体两两最小距离增大则接受；
4. **去重与截断**：保证最终输出 `n` 注不重复号码。

该算法在完全随机的基础上，通过局部搜索提升空间分散度，符合概率统计中「均匀覆盖样本空间」的思想。

## 4. 关键接口

- **策略 ID**：`dispersed_random_3d`
- **显示名称**：分散随机
- **输入参数**：
  - `count`（int）：生成注数，默认 20
  - `seed`（int | None）：可选随机种子，用于复现结果
  - `pool_factor`（int）：候选池倍数，默认 5
- **返回**：`List[Tuple[int, int, int]]`，每注为 `(百位, 十位, 个位)`

## 6. 使用方法

启动应用后，进入福彩3D生成界面，在策略下拉列表中选择「分散随机」，设置生成注数（默认 20），点击生成即可。

## 7. 后续可改进点

- 当前优化目标为最小两两距离，可考虑加入「覆盖半径」或「D-最优设计」等更高级的实验设计准则；
- 可考虑允许用户选择「完全均匀覆盖」与「带随机扰动的分散」两种模式；
- 分散度指标可在 UI 上可视化展示，增强可解释性。
