# 彩种介绍

本工具支持以下彩种玩法，每种玩法均可独立生成号码、分析历史数据、训练预测模型。

- 福利彩票：双色球、福彩3D、七乐彩、快乐8
- 体育彩票：超级大乐透、排列3、排列5、7星彩、广东36选7

---

## 双色球（SSQ）

| 项目 | 说明 |
|------|------|
| 号码结构 | 红球 6 个 + 蓝球 1 个 |
| 号池 | 红球：1–33，蓝球：1–16 |
| 开奖日 | 每周二、四、日 |
| 单注金额 | 2 元 |

### 玩法规则

从 33 个红球中选 6 个（不重复），从 16 个蓝球中选 1 个，组成一注。

### 奖级

| 奖级 | 条件 |
|------|------|
| 一等奖 | 6 红 + 1 蓝 |
| 二等奖 | 6 红 + 0 蓝 |
| 三等奖 | 5 红 + 1 蓝 |
| 四等奖 | 5 红 + 0 蓝，或 4 红 + 1 蓝 |
| 五等奖 | 4 红 + 0 蓝，或 3 红 + 1 蓝 |
| 六等奖 | 2 红 + 1 蓝，或 1 红 + 1 蓝，或 0 红 + 1 蓝 |

### 本工具支持的策略

完全随机、奇偶均衡、冷热号分析、排除/必含、智能冷热号、遗漏号追踪、历史均衡、XGBoost 智能分析、LightGBM 智能分析。

## 福彩3D（FC3D）

| 项目 | 说明 |
|------|------|
| 号码结构 | 3 位数字（百位、十位、个位） |
| 号池 | 每位 0–9，可重复 |
| 开奖日 | 每日 |
| 单注金额 | 2 元 |

### 玩法规则

从 0–9 中选出 3 个数字（可重复），按顺序组成一注。每位独立，顺序有意义。

### 常见投注方式

| 方式 | 说明 | 示例 |
|------|------|------|
| 直选 | 3 位数字与开奖号码完全一致（顺序一致） | 3 7 5 |
| 组选三 | 3 位数字中有两个相同（不计顺序） | 1 6 1 |
| 组选六 | 3 位数字各不相同（不计顺序） | 3 7 5 |
| 豹子号 | 3 位数字全部相同，只能按直选购买 | 7 7 7 |

### 投注方式提示

软件生成福彩3D 号码后，会根据号码特征在主界面、可视化球行、PDF/打印输出中自动标注建议投注方式：

- 三位各不同 → **组选6**
- 恰好两位相同 → **组选3**
- 三位全相同 → **豹子号（直选）**

实际投注时仍可按个人偏好选择直选或组选。

### 本工具支持的策略

完全随机、奇偶均衡、冷热号分析、排除/必含、智能冷热号、遗漏号追踪、历史均衡、XGBoost 智能分析、LightGBM 智能分析。

## 快乐8（KL8）

| 项目 | 说明 |
|------|------|
| 号码结构 | 开奖 20 个号，玩家选 1–10 个 |
| 号池 | 1–80 |
| 开奖日 | 每日 |
| 单注金额 | 2 元 |

### 玩法规则

从 1–80 中开出 20 个号码。玩家可选择投注 1 到 10 个号码，投注个数越多，中奖概率越高，单注奖金相应调整。

### 玩法等级

| 玩法 | 选号个数 | 中 1 个奖金参考 |
|------|----------|----------------|
| 一选 | 1 个 | 4.6 元 |
| 二选 | 2 个 | 约 9 元起 |
| 三选 | 3 个 | — |
| … | … | … |
| 十选 | 10 个 | — |

> 具体奖级与奖金以中国福利彩票官方公布为准。

### 本工具支持的策略

快乐8 支持可变投注个数（1–10），在使用策略时可通过「投注个数」参数调整。

#### 智能冷热号

在每号每期独立同分布（p=0.25）的零假设下，用统计显著的冷热信号驱动加权采样：
- 热号信号：拉普拉斯平滑频率
- 冷号信号：遗漏期数 → 几何分布 z-score（z>1.96 才算显著偏冷）
- χ² 均匀性检验守卫：防止把随机噪声当作预测信号
- z-score 标准化 + softmax 温度控制

#### 历史均衡（增强版）

基于 7 维统计特征生成均衡号码，使各维度接近历史平均：

| 维度 | 说明 | 惩罚方式 |
|------|------|----------|
| 奇偶比 | 奇数/偶数个数 vs 历史平均 | 平方惩罚 |
| 大小比 | 大号(>=41)/小号个数 vs 历史平均 | 平方惩罚 |
| 和值 | 号码总和 vs 历史平均范围 | 渐进惩罚 |
| 三区分布 | 1-27/28-54/55-80 各区号码数 | 平方惩罚 |
| 连号对数 | 相邻号码对数 vs 历史平均 | 平方惩罚 |
| 覆盖度 | 号码在 8 个分段中的覆盖比例 | 不足时放大惩罚 |
| 邻期重合 | 与上期号码重合数 vs 历史平均 | 平方惩罚 |

采样改进：
- 基于拉普拉斯平滑频率的引导采样
- 分段采样（8 段 × 10 号），保证号码全局分散性
- χ² 均匀性检验信息纳入说明
- 7 个独立权重滑块，用户可按需调整各维度重要性

## 超级大乐透（DLT）

| 项目 | 说明 |
|------|------|
| 号码结构 | 前区 5 个 + 后区 2 个 |
| 号池 | 前区：1–35，后区：1–12 |
| 开奖日 | 每周一、三、六 |

### 玩法规则

从前区 1–35 中选 5 个（不重复），从后区 1–12 中选 2 个（不重复），组成一注。追加投注可提升一、二等奖奖金。

| 一等奖 | 5 前区 + 2 后区 |
| 二等奖 | 5 前区 + 1 后区 |
| 三等奖 | 5 前区 + 0 后区 |
| 四等奖 | 4 前区 + 2 后区 |
| 五等奖 | 4 前区 + 1 后区 |
| 六等奖 | 3 前区 + 2 后区 |
| 七等奖 | 4 前区 + 0 后区 |
| 八等奖 | 3 前区 + 1 后区，或 2 前区 + 2 后区 |
| 九等奖 | 3 前区 + 0 后区，或 1 前区 + 2 后区，或 2 前区 + 1 后区，或 0 前区 + 2 后区 |

### 本工具支持的策略

## 策略说明

本工具内置以下 9 种号码生成策略，适用于所有彩种：

| 策略 | 说明 | 是否需要历史数据 |
|------|------|:---:|
| 完全随机 | 在号池范围内等概率随机抽取 | 否 |
| 奇偶均衡 | 控制奇数和偶数的比例 | 否 |
| 冷热号分析 | 基于历史频率优先选择热号或冷号 | 是 |
| 排除/必含 | 排除不想要的号码，或强制包含某些号码 | 否 |
| 智能冷热号 | 综合热号频率与冷号遗漏值加权生成 | 是 |
| 遗漏号追踪 | 选择近期遗漏值较高的号码 | 是 |
| 历史均衡 | 基于 7 维统计特征（奇偶/大小/和值/三区/连号/覆盖度/邻期重合）生成均衡号码 | 是 |
| XGBoost 智能分析 | 基于 XGBoost 模型分析历史数据 | 是 |
| LightGBM 智能分析 | 基于 LightGBM 模型分析历史数据 | 是 |

### 使用建议

1. **更新数据**：在「开奖数据」页签点击「更新全部数据」获取最新历史记录。
2. **选择策略**：在「生成号码」页签选择合适的策略。
3. **查看结果**：点击「立即生成」获取号码，可复制、打印或导出 PDF。
4. **训练模型**：ML 策略首次使用时会自动训练模型，后续使用缓存加速。
