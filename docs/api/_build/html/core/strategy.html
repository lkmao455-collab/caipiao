class caipiao.core.strategy.GenerationStrategy[source]

Bases: ABC

号码生成策略基类.

所有自定义策略都必须继承此类，并实现 generate 方法。 策略可通过插件机制动态加载。

is_ml: bool = False

标记该策略是否为机器学习策略；批量回测 worker 会据此决定 是否在子进程中预先训练模型。插件 ML 策略也应置为 True。
