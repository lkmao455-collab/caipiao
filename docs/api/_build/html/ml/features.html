caipiao.ml.features.build_features(records: List[DrawRecord], lookback: int = 50) → Tuple[ndarray, ndarray, ndarray][source]

构建训练特征和标签（仅支持双色球）.

Parameters:

  • records – 按时间排序的开奖记录（必须为双色球）。

  • lookback – 回看期数。

Returns:

特征矩阵，形状 (samples, features) y_red: 红球标签，形状 (samples, 33)，每列为是否出现 y_blue: 蓝球标签，形状 (samples, 16)，每列为是否出现

Return type:

X

caipiao.ml.features.build_incremental_features(records: List[DrawRecord], lookback: int = 50, new_count: int = 1) → Tuple[ndarray, ndarray, ndarray][source]

构建增量训练特征（仅支持双色球）。

只为最近 new_count 期构建特征，用于增量训练。

Parameters:

  • records – 按时间排序的全部开奖记录。

  • lookback – 回看期数。

  • new_count – 需要构建特征的新记录数量。

Returns:

新特征矩阵 y_red_new: 新红球标签 y_blue_new: 新蓝球标签

Return type:

X_new
