model

XGBoost 模型训练与预测（顺序组合生成版）.

为双色球红球建模为不放回顺序生成问题： 给定历史窗口特征和已选红球，预测下一个红球号码。 蓝球仍按 16 个二分类器建模（每期只开 1 个蓝球）。

class caipiao.ml.model.LotteryXGBoostModel(lookback: int = 50, temp_dir: str | None = None)[source]

Bases: object

基于 XGBoost 的彩票号码分析模型.

红球：顺序生成模型，输入包含历史特征、已选红球 mask、当前步数。 蓝球：为每个蓝球训练二分类器，输出下一期出现的概率。
