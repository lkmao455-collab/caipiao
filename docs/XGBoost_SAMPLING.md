# XGBoost 策略“概率加权采样”详解

> 本文档面向希望理解软件内部机制的用户，重点解释：
> 1. 为什么第一组号码固定取“概率最高的前 6 红 + 前 1 蓝”；
> 2. 其余号码组是如何“按预测概率加权采样”生成的；
> 3. 固定随机种子如何保证结果可复现；
> 4. 这一过程背后的科学原理与适用边界。

---

## 1. 从模型输出到号码概率

XGBoost 模型本质上为 33 个红球和 16 个蓝球各自训练了二分类器：

- 输入：最近 `lookback` 期开奖数据的统计特征（频率、遗漏值、奇偶比、大小比、和值、连号率等）。
- 输出：每个号码在“下一期出现”的概率，分别记为：

```
P_red(i)    : 红球 i 在下一期出现的概率，i = 1, 2, ..., 33
P_blue(j)   : 蓝球 j 在下一期出现的概率，j = 1, 2, ..., 16
```

这些概率满足：

```
0 ≤ P_red(i) ≤ 1,    0 ≤ P_blue(j) ≤ 1
```

**注意**：模型输出的不是“中奖概率”，而是“基于历史统计模式的相对倾向”。它不能预测独立随机事件，只能描述历史数据中的统计特征。

---

## 2. 第一组：确定性 top-K

为了让结果具有明确的“模型最看好”参考意义，第一组号码直接取：

- 红球：预测概率最高的 6 个；
- 蓝球：预测概率最高的 1 个。

这是一个**确定性选择**（deterministic selection），不引入随机性。在完全相同的输入数据和参数下，第一组永远相同。

数学表达：

```
TopReds   = argsort_desc(P_red)[0:6]  对应的号码
TopBlue   = argmax(P_blue) 对应的号码
```

---

## 3. 其余组：概率加权采样（Probability-Weighted Sampling）

如果所有组都取 top-K，那就失去了“探索其他可能组合”的意义。因此其余组采用**概率加权随机采样**：

> 每个号码被选中的可能性与其预测概率成正比，概率越高的号码越容易被选中，但低概率号码仍有被抽中的机会。

### 3.1 权重归一化

模型输出的概率不一定能直接作为抽样权重使用。代码中做了两步处理：

```python
red_weights = red_proba + 0.05
red_weights = red_weights / red_weights.sum()
```

- **加 0.05**：避免某些号码的预测概率接近 0 时完全丧失被抽中的机会。这相当于给每个号码一个“基线机会”。
- **除以总和**：将所有权重归一化为概率分布，使其满足：

```
Σ w_i = 1,   且 w_i ≥ 0
```

这样，`red_weights` 就是一个合法的多项分布（categorical distribution）。

### 3.2 红球：不放回加权抽样

双色球的红球要求 6 个号码不重复，因此采用**不放回抽样（sampling without replacement）**。

具体流程：

```
已选集合 selected = ∅
可选集合 available = {1, 2, ..., 33}
权重向量 weights   = red_weights

循环直到 |selected| = 6:
    1. 按当前 weights 从 available 中随机抽取一个号码 n
    2. 将 n 加入 selected
    3. 将 n 从 available 中移除
    4. 删除 weights 中对应 n 的权重
    5. 若启用多样性增强，降低与 n 相邻号码的权重
    6. 重新归一化 weights
```

每一步都是“在当前可选集合上的条件加权抽样”。

### 3.3 蓝球：不放回加权抽样

蓝球只选 1 个，同样使用归一化后的蓝球权重做一次性抽样：

```python
blue = np.random.choice(range(1, 17), size=1, replace=False, p=blue_weights)
```

### 3.4 多样性增强（Diversity Boost）

如果只按概率抽样，模型可能每次都选出数值接近的号码（例如 12、13、14、15 等）。为了让号码分布更分散，代码引入了**多样性增强**：

```python
for s in selected_reds:
    for neighbor in [s-1, s, s+1]:
        降低 neighbor 的权重
```

- 当某个号码被选中后，它左右相邻的号码在后续抽取中被惩罚；
- 惩罚强度由 `diversity_boost` 控制，取值 0~10，内部换算为 0.0~1.0；
- 惩罚后重新归一化权重，保证仍然是一个合法的概率分布。

这一步借鉴了统计抽样中的**负相关抽样（negative correlation / repulsive sampling）**思想：在保持概率倾向的同时，让最终样本在空间上更分散。

## 4. 固定随机种子：科学实验的可复现性

自然界中真正的随机事件无法复现，但计算机中的“随机”其实是**伪随机（pseudo-random）**。

### 4.1 伪随机数生成器（PRNG）

NumPy 的 `RandomState(seed)` 是一种确定性算法：

```
给定同一个 seed，它产生的随机数序列完全相同。
```

例如：

```python
np_rng = np.random.RandomState(42)
print(np_rng.random(5))  # 每次运行结果都一样
```

### 4.2 固定种子的作用

在 XGBoost 策略中，我们为第 i 组号码固定派生种子：

```python
np_rng = np.random.RandomState(FIXED_SEED + i)
```

其中 `FIXED_SEED = 42` 是常数。

这意味着：

- 只要历史数据、模型参数、多样性增强、生成注数相同，每一次启动软件生成的号码组都完全相同；
- 不同组之间使用不同种子（`42+1`、`42+2`…），保证组间差异；
- 用户可以把结果截图保存，过了几天再用同样数据复跑，结果不变，便于验证和讨论。

这符合科学实验的**可重复性（reproducibility）**原则。

## 5. 背后的科学原理

### 5.1 概率比例抽样（PPS, Probability Proportional to Size）

“按概率加权抽样”是抽样调查中的经典方法。它的核心思想是：

> 总体中每个个体被抽中的概率与其某个指标大小成正比。

在我们的场景里，这个“指标”就是模型预测的号码出现倾向。概率高的号码获得更高权重，但低概率号码不会被完全排除。

### 5.2 蒙特卡洛模拟（Monte Carlo Simulation）

加权采样多次生成多组号码，本质上是在模型学习到的概率分布下进行**蒙特卡洛模拟**：

- 每组号码都是该分布的一次“可能实现”；
- 多次模拟可以观察模型倾向的稳定性；
- 统计多组号码中各号码出现的频率，能反向验证模型是否真的偏好某些号码。

### 5.3 最大熵与正则化

加 0.05 的基线权重和多样性增强，实际上是在模型预测之外加入**正则化**：

- 不加基线：模型可能把某些号码概率压到接近 0，导致这些号码永不被选中；
- 不加多样性增强：可能反复选中相邻号码，失去组合多样性；
- 两者结合，让采样结果既尊重模型，又保留一定探索空间。

## 6. 重要边界与免责声明

以上所有方法都建立在同一个前提上：

> **历史数据中存在的统计模式，不代表未来开奖会重复这些模式。**

双色球开奖是独立随机事件。XGBoost 只能拟合历史数据中的噪声与短期统计波动，它输出的概率只是“历史回顾概率”，不是“未来发生概率”。

因此：

- 概率加权采样让号码生成更“有依据”，但**不能提高中奖率**；
- 固定种子保证可复现，只是方便学习和验证，不能据此认为某组号码“更可能中奖”；
- 本软件的全部功能应作为**概率统计与机器学习的学习工具**使用，而非投注建议。

## 7. 小结

| 步骤 | 操作 | 目的 |
|------|------|------|
| 模型预测 | XGBoost 输出 33+16 个概率 | 量化历史统计倾向 |
| 第一组 | 取 top-6 红球 + top-1 蓝球 | 给出模型最看好的确定性参考 |
| 其余组 | 概率加权随机采样 | 在模型分布下探索多种可能组合 |
| 多样性增强 | 惩罚相邻号码 | 避免号码过度集中 |
| 固定种子 | `RandomState(42 + i)` | 保证实验可复现 |

这就是 XGBoost 智能分析策略中“其余注按概率加权采样，并保持固定种子以确保可复现”的完整含义。
