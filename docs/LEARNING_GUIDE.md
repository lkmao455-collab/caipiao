## 1. 双色球规则与组合数

双色球从 1–33 中选 6 个红球（不重复、不计顺序），再从 1–16 中选 1 个蓝球。

总组合数为：

```
C(33, 6) × 16 = 1,107,568 × 16 = 17,721,088
```

因此每注一等奖的理论概率约为 **1 / 17,721,088 ≈ 5.64 × 10⁻⁸**。这个数字提醒我们：任何号码生成方法都无法把中奖概率提高到显著水平。

> 教学意义：理解“组合数爆炸”和“稀有事件”的概念。

## 2. 概率论基础

### 2.1 独立事件

每一期开奖都是独立的——上一期的结果不会影响下一期。换句话说，即使红球“01”连续 100 期没出现，下一期它出现的概率仍然是 **6/33**（在单独一个号码的视角下）。

软件中的“随机策略”就是严格遵循独立事件的假设：每个有效组合被抽中的概率相等。

### 2.2 大数定律

当开奖次数趋于无穷时，每个号码出现的频率会趋近于其理论概率。但“趋于”是一个长期过程，短期偏差可能很大。

冷热号策略正是基于“长期频率会回归均值”的直觉，但要注意：**大数定律不保证短期会回调**。

### 2.3 期望与赔本风险

假设单注 2 元，一等奖奖金波动较大，若用期望计算：

```
期望收益 = 中奖概率 × 奖金 - 成本
```

由于中奖概率极低，长期大量购买彩票的期望收益通常为负。软件中的统计功能可以帮助你理解这一点，而不是鼓励盲目投注。

## 3. 统计指标解析

### 3.1 热号与冷号

- **热号**：在最近的 N 期中出现频率较高的号码。
- **冷号**：在最近的 N 期中出现频率较低的号码。

公式：

```
频率 = 某号码在回望期数内出现的次数 / 回望期数
```

热号策略倾向选择“近期表现活跃”的号码；冷号策略则倾向选择“近期表现低迷”的号码。两者都只是一种基于历史数据的**启发式**，不代表未来走势。

### 3.2 遗漏值

遗漏值 = 某号码距离上一次出现之间的期数。

遗漏号策略认为“长时间未出现的号码未来更可能出现”。这其实是对“赌徒谬误”的反向利用——同样没有概率上的必然性。

### 3.3 奇偶比与大小比

- 奇偶比：红球中奇数与偶数的个数比例。
- 大小比：通常以 17 为界，红球中“小号（1–16）”与“大号（18–33）”的比例。

在历史开奖中，3:3、4:2、2:4 这类较均衡的奇偶比出现频率较高。均衡策略会让生成结果尽量符合常见比例，但并不能提高中奖率。

### 3.4 和值与连号率

- **和值**：6 个红球相加的总和。
- **连号率**：相邻号码成对出现的频率。

通过分析历史数据的分布，可以发现和值多集中在中间区间。均衡策略会尝试让和值落在常见区间，让号码“看起来更像历史开奖”。

## 4. 机器学习建模思路

### 4.1 问题定义

把双色球看作一个多分类问题并不合适，因为每一期都是独立的。但在学习层面，我们可以训练模型来：

1. 根据最近若干期的特征，预测每个红球和蓝球的“出现倾向”。
2. 用历史数据验证模型是否能学到某些短期统计规律。
3. 理解特征工程、时序数据、模型评估等通用机器学习流程。

### 4.2 特征工程

在 `caipiao/ml/features.py` 中，我们构造了多种特征：

- 近期出现频率
- 遗漏值
- 奇偶比、大小比
- 和值、连号率
- 时间/期号相关的位置编码

这些特征并不具备预测未来的能力，但可以用于练习“如何把领域知识转化为数值特征”。

### 4.3 XGBoost 模型

XGBoost 是一种梯度提升决策树算法，擅长处理表格型特征。软件为每个红球和蓝球分别建立二分类器：

```
输入：最近一段时间的开奖特征
输出：该号码在下一期出现的概率
```

模型训练后会以时间戳命名缓存在应用目录下的 `.caipiao/models/xgboost_lookback{lookback}_{时间戳}.pkl`（保留历史版本），删除后可重新训练。

### 4.4 为什么不能预测开奖？

机器学习只能拟合训练数据中的统计模式。如果开奖真的是独立随机的，那么历史模式中包含的“规律”只是噪声，模型学到的也是噪声。下次开奖时，这些噪声不会复现。

> 这是本软件最重要的教学点：**不要让“模型看起来有效”的幻觉，掩盖了随机性的本质。**

## 5. 生成策略一览

| 策略 | 原理 | 是否有历史数据依赖 |
|------|------|------------------|
| 随机策略 | 完全随机，等概率 | 否 |
| 奇偶均衡 | 控制奇偶比接近常见比例 | 否（仅规则） |
| 冷热号 | 优先选近期热号/冷号 | 是 |
| 遗漏号 | 优先选遗漏期数较长的号码 | 是 |
| 智能冷热 | 结合频率与和值等约束 | 是 |
| 历史均衡 | 让号码整体分布接近历史统计 | 是 |
| XGBoost | 用机器学习预测号码倾向 | 是 |
| 排除/必含 | 用户指定排除或必含号码 | 否（用户输入） |
| 插件策略 | 用户自定义 Python 策略 | 视实现而定 |

建议初学者从“随机策略”和“奇偶均衡”开始，理解基础概率；进阶学习可以尝试“XGBoost 策略”，观察模型训练、预测和推荐过程。

## 6. 使用建议与常见问题

### 6.1 数据更新

- 启动时自动检查更新由两个设置共同控制（均在"设置"页）：
  - **「启动时自动检查更新」开关**：关闭后，启动时**完全不执行**任何检查，进度对话框也不会弹出。若发现软件从不自动更新，请先确认此开关已勾选。
  - **「检查间隔（天）」**：默认 1 天。即使开关开启，也只有距上次成功更新超过该间隔时才联网检查（例如设为 30 则每 30 天最多检查一次）。同一天内多次启动不会重复检查，这是设计行为。
- 开关开启且间隔已过期时，软件会弹出"正在更新开奖数据"对话框，静默尝试下载最新一期开奖数据；无网络时自动回退到本地数据，不影响使用。
- 手动点击"更新开奖数据"会下载 2003 年至今的完整数据。
- 数据源优先级：`17500.cn` → `500.com` → `中彩网`。

### 6.2 模型训练

- 点击「训练模型」会先联网拉取最新一期开奖数据并入库（离线时用本地数据继续），再开始训练，确保基于最新数据。
- XGBoost 首次训练约 10–20 秒，取决于电脑性能。
- 训练在后台线程进行，全程弹出模态进度窗口显示进度；训练期间无法操作主界面，避免重复训练等无效操作。
- 模型按时间戳命名保存，保留历史版本；删除模型缓存后会重新训练。
- 使用「XGBoost 智能分析」生成号码时，会自动检查模型是否与当前数据匹配；不匹配（例如数据已更新）会先自动训练再生成。

### 6.3 打印与导出 PDF

- “打印结果”依赖系统打印机驱动，如果驱动异常会提示错误。
- “导出 PDF”不依赖打印机，可直接生成 PDF 文件。
- PDF 中的概率折线图采用横向网格布局，宽度自适应页面，避免被压缩得过小或与号码文字重叠。

### 6.4 启动时的字体警告

如果启动时终端出现 `QFont::setPointSize: Point size <= 0 (-1), must be greater than 0`，通常是因为 Qt 样式表使用了 `px` 作为字体单位，导致部分控件字体解析为负数点大小。本软件已将全局样式表和主要控件字体统一改为 `pt` 单位来避免该警告。

### 6.5 插件扩展

- 插件目录可在“插件”标签页中查看或修改。
- 自定义策略需要实现 `GenerationStrategy` 接口，参考 `caipiao/plugins/` 中的示例。
